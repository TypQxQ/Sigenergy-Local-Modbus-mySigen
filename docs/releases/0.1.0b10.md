# Sigenergy ESS – mySigen cloud 0.1.0 Beta 10

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. Every release is a beta for now, so enable prereleases for this repository in the Marketplace first; without them the install fails with a download error. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b10/README.md) for setup and the [guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b10/docs/USAGE.md) for every entity.

- **Settings at setup.** Once the account is checked against your plant, a second screen asks for the polling interval, **Allow battery control** and **Allow disconnecting from the grid**. Both control options start off. You no longer have to open Reconfigure afterwards; the same settings stay there to change later.
- **Clearer help for battery control** in all eleven languages: it now says the option also covers plant and DC charger settings, not only overrides.
- **Install steps** in the README now say to enable prereleases before installing.

Existing connections keep their settings and entity IDs. Have another system, a Gateway or a DC charger? [Join the test](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/discussions/20); even a diagnostics file helps.
