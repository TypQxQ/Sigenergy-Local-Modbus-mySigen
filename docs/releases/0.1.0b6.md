# Sigenergy ESS – mySigen cloud 0.1.0 Beta 6

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is an unofficial project that uses the mySigen app's private interface, which Sigenergy can change or close at any time. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b6/README.md) for setup and limitations.

**Entity names changed.** Battery override is now *Battery override active*, Battery override end is *Battery override ends*, Battery override command is *Last battery override result*, and Last mySigen update is *mySigen last update*. Existing installs keep their entity IDs. **Gateway grid frequency** and **Gateway grid contactor** are removed because Sigenergy Local Modbus already provides them; update any automation or dashboard that uses them.

- **More battery overrides.** Charge battery, Discharge battery and Use my own solar first (self-consumption), next to Hold battery. Each ends by itself when the time is up, and Sigen AI stays the operating mode.
- **Power limit** for charging and discharging: a number entity (0 = no limit, disabled by default) and a `power_limit` field on the start action.
- **Dashboard controls** while battery control is allowed: a dropdown for the override, its duration, and Start and Stop buttons.
- **More Gateway sensors** at no extra requests: highest and lowest voltage in the past minute per phase, phase sequence, firmware and model, and generator readings. Only firmware and model are enabled by default.
- **Eleven languages**, the same as Sigenergy Local Modbus. Entity names follow the plant's *Entity name language* setting. Languages other than English and Swedish are unreviewed; corrections are welcome.
- **Fewer requests.** A system without a Gateway is asked about it once an hour instead of on every poll.
- **Fixes.** A command's confirmed result is no longer overwritten by a poll that was already under way.

All four override modes and the power limit were tested on one European plant. Please report results from other regions, models and firmware in an issue, with the diagnostics file attached.

The plan for upcoming features is in [docs/PLAN.md](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b6/docs/PLAN.md).
