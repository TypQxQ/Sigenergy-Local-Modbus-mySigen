# Sigenergy ESS – mySigen cloud 0.1.0

The first stable release. A default install from the Marketplace now works without enabling prereleases.

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is an unofficial project that uses the mySigen app's private interface, which Sigenergy can change or close at any time. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0/README.md) for setup and the [guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0/docs/USAGE.md) for every entity.

Nothing changed in the add-on since 0.1.0 Beta 10; existing connections keep their settings and entity IDs.

- **Tested on a real plant:** battery overrides, operating mode, battery export, peak shaving and the Gateway readings, on one European system with a Gateway and no charger.
- **Built but not yet tried for real:** disconnecting from the grid and the DC charger controls. Both start off and disabled.
- **Translations:** nine of the eleven languages still need a native speaker's review.

Have another system, a Gateway you can safely take off-grid for a moment, or a DC charger? [Join the test](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/discussions/20); even a diagnostics file helps.
