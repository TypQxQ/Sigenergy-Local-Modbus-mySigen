# Sigenergy ESS – mySigen cloud 0.1.2 Beta 2

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is a beta: enable prereleases for this repository in the Marketplace to get it. Turning prereleases off later offers the latest stable version, which can be older than this beta.

Fixes from purcell-lab's installation report (issues 31 to 36) and TD944's test in [discussion 38](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/discussions/38). Thank you!

- **Operating mode no longer shows unknown in Remote EMS.** The dropdown now shows the mode the plant runs in, also when it can't be chosen here: Remote EMS, a custom profile, VPP scheduling, force charge or NBI. The `mode_code` attribute has mySigen's number for it. Choosing one of those is refused with the reason. (Issue 32)
- **Peak shaving grid limit explains itself.** It no longer turns unavailable when the schedule has no time slot or several: it shows unknown, the `time_slots` attribute says how many there are, and a change says what to set up in the app. (Issue 34)
- **Charger changes wait for the charger.** A DC or AC charger confirms a change a few seconds after the plant, so the add-on now waits up to about ten seconds before calling it unconfirmed. Any change that is accepted but not shown yet is read again at the next update. (Discussion 38)
- **Remote EMS in the guide.** A short list of what Remote EMS blocks and what still works. Battery export, peak shaving and the max grid connection current stay allowed: Modbus can't change them, so they don't compete with the controller running Remote EMS. (Issue 33)
- **Ready for aiohttp 4.** The sign-in request builds its Authorization header itself instead of the deprecated `aiohttp.BasicAuth`. (Issue 36)
- **Install note** about turning prereleases off, which offers an older stable version as an update. (Issue 35)

Existing connections keep their settings and entity IDs. Everything from 0.1.2 Beta 1 is included, with the AC charger controls still waiting for a tester with a charger.
