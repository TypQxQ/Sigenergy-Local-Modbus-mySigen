# Sigenergy ESS – mySigen cloud 0.1.0 Beta 2

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is an unofficial project that uses the mySigen app's private interface, which Sigenergy can change or close at any time. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b2/README.md) for setup and limitations.

- **Swedish translation** for the setup, re-sign-in and Reconfigure dialogs, errors, repair notices, the two actions and the entity states. Entity names stay in English in every language, so entity IDs match the documentation.
- **Marketplace category.** The add-on is now listed under solar and batteries.

No changes to readings or battery control since Beta 1.
