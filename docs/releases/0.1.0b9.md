# Sigenergy ESS – mySigen cloud 0.1.0 Beta 9

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is an unofficial project that uses the mySigen app's private interface, which Sigenergy can change or close at any time. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b9/README.md) for setup and the [guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b9/docs/USAGE.md) for every entity.

**Entity names changed.** Every name now ends with *(mySigen)*, so these stand apart from the Modbus entities on the same device. Many are shorter and clearer, for example *Start battery override*, *Next override mode*, *Last override command result* and *Battery override end time*. Existing installs keep their entity IDs, and names you set yourself stay. On a new install, entity IDs typically end in `_mysigen`.

- **Plant settings** while battery control is allowed: Operating mode, Allow battery export to grid, Peak shaving and its grid limit. Unlike an override, they stay until you change them back. They start disabled.
- **Disconnect from grid**, a switch that runs the home on battery and solar alone, for plants with a Sigenergy Gateway. It needs the new **Allow disconnecting from the grid** option under Reconfigure, which is off by default, and starts disabled. The grid status reads correctly, but no disconnect has been sent on a real plant yet.
- **DC charger**, when mySigen lists one: the charging mode, charge limit, minimum EV charge for V2X, and whether the car may power the home. These were built from other mySigen clients and have **not been tried on a real charger**.
- **The same rules for every change.** The current value is read first and nothing is sent when it is already set; a change is sent once, never repeated, and only counts when the plant shows it. Changes are refused while Remote EMS is on or while mySigen asks for fewer requests.
- **Clearer wording** in all eleven languages. Finnish now calls the override *akun tilapäinen ohjaus*.
- **Fixes.** A different mySigen system is never taken over without checking it against the plant again. The DC charger list is read again every hour, and a failed charger read is retried once after a minute instead of keeping old values.
- **New README, guide and roadmap**: a short first page, every entity and control in [docs/USAGE.md](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b9/docs/USAGE.md), and what is tested and planned in [docs/PLAN.md](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b9/docs/PLAN.md).

The overrides, settings and Gateway readings were tested on one European plant with a Gateway and no charger. Have another system, a Gateway you can safely take off-grid for a moment, or a DC charger? [Join the test](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/discussions/20); even a diagnostics file helps.
