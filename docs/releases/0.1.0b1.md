# Sigenergy ESS – mySigen cloud 0.1.0 Beta 1

First public beta. An optional add-on for [Sigenergy Local Modbus](https://github.com/TypQxQ/Sigenergy-Local-Modbus) that adds mySigen cloud readings and a timed battery Hold to the plant device the Modbus integration already created.

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is an unofficial project that uses the mySigen app's private interface, which Sigenergy can change or close at any time. See the [README](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.0b1/README.md) for setup and limitations.

- **Battery override status.** Shows whether a temporary override (Instant Manual Control) is running, its mode and its end time, whoever started it.
- **Gateway readings.** Grid voltage and current per phase, frequency and contactor state, on systems with a Gateway.
- **Timed Hold Battery.** Two actions start and cancel a 30 to 120 minute Hold. The plant ends it by itself, also when Home Assistant is stopped. Control is off until you switch it on under Reconfigure, and a start is refused while another override or Remote EMS is active.
- **Safe linking.** Setup refuses an account whose system does not contain the plant's inverter.
- **Diagnostics** without password, email, token, station ID or serial numbers.

Verified on one European system with one inverter and a Gateway. Please report results from other regions, models and firmware in an issue, with the diagnostics file attached.
