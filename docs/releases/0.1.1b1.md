# Sigenergy ESS – mySigen cloud 0.1.1 Beta 1

**Before installing.** Requires Home Assistant Core 2026.11.0 or later and Sigenergy Local Modbus 2.0.3 or later with a plant set up. This is a beta: enable prereleases for this repository in the Marketplace to get it. See the [guide](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/blob/v.0.1.1b1/docs/USAGE.md#-battery-modules) for every new entity.

- **Battery modules.** Each module mySigen lists gets its own device, **Sigen battery module 1**, 2 and so on, placed under its inverter. It shows the module's model, firmware and rated capacity, its average cell temperature and voltage, and its lifetime discharge in kWh. Modbus only reads the battery as a whole, so none of this repeats what Sigenergy ESS shows. mySigen gives no charge level or power per module.
- **Few extra requests.** One module is read per poll, and each module again about every five minutes (longer with many modules or a long polling interval); model and rated capacity once a day. The module list is checked again every hour.
- **Diagnostics** now include which module fields arrived, why a read failed, and the structure of the module answers, with every value masked and no serial numbers.

Tested on one plant with four SigenStor BAT 8.0 modules. Asked for in [discussion 20](https://github.com/TypQxQ/Sigenergy-Local-Modbus-mySigen/discussions/20) for tools such as [BatteryLedger](https://github.com/Roving-Ronin/BatteryLedger); the request formats follow [sigenergy2mqtt](https://github.com/seud0nym/sigenergy2mqtt).

Nothing else changed; existing connections keep their settings and entity IDs.
